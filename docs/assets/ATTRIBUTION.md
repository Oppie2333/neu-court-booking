# 设计与图片来源

## 像素 Q 版南湖校门与羽毛球运动插画

`neu-nanhu-pixel.png` 为本项目通过 CCS ImageGen 辅助生成的校园运动主题插画，随项目按 MIT 许可提供。它是像素 Q 版艺术示意，不是实景照片，也不是学校官方标志或校徽。

| 项目 | 记录 |
| :--- | :--- |
| 生成日期 | 2026-10-19 |
| 生成方式 | CCS ImageGen，`edit`；参考图为本项目先前通过纯文字生成的校园概念图，未上传实景照片 |
| 模型 | `gpt-image-2` |
| 比例与质量 | `16:9`，`clarity=high`，Image API `quality=high` |
| 尺寸 | 接口原始结果 1672 × 941；包装器规范化为 2048 × 1152；README 保持该尺寸 |
| 本地处理 | 转为 256 色 PNG 并优化压缩，不改变构图；发布图片约 805 KiB |
| 完整编辑提示词 | [neu-nanhu-pixel.prompt.txt](neu-nanhu-pixel.prompt.txt) |

设计将灰色石门柱、右柱竖排“东北大学”、中轴暖黄色教学楼与跃起扣杀的羽毛球运动员、球拍和球场结合，使用深蓝、青绿、石灰与金色配色，突出校园辨识度与运动感。图中球场位置及建筑比例是艺术化处理，不用于指引真实场馆位置。

## 原创矢量设计

`logo.svg` 为本项目制作的像素风矢量标志，以米白羽毛球、南湖双门柱轮廓与青绿色球场线为元素，使用深蓝底和淡金细节，呼应页首插画；不使用外部图片或字体。`hero.svg` 为项目早期的羽毛球主题矢量横幅。两者均采用项目 MIT 许可，不是东北大学校徽。

## 历史版本

当前分支已移除校门摄影素材。旧版 `v1.0.0` 源码中包含的照片及其独立许可，以该标签内的素材署名文件为准。
