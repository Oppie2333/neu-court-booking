# 使用说明

## 1. 准备

- 使用 Windows 10/11 64 位电脑，安装 Google Chrome。
- 确认自己能在学校网站正常登录并具有场馆预约权限；校外访问以学校实际要求为准。
- 准备同行人姓名和学校统一认证账号（学号/工号），按学校要求填写。
- 运行前先通过系统设置校准电脑时间。界面内的任务时间均为北京时间。

把 Windows 运行包完整解压，双击 `NEUCourtBooking.exe`。无需安装 Python。首次打开预约浏览器会联网下载匹配的驱动，建议提前完成，不要等到放号瞬间才启动。

## 2. 填写任务

程序启动后不会自行预约，需要你设置并开始任务。

当前版本为 **1.1.0 预发布测试版**。从 [v1.1.0 Release](https://github.com/Oppie2333/neu-court-booking/releases/tag/v1.1.0) 下载 `NEUCourtBooking-1.1.0-windows-x64.zip`；以下说明对应本版本。

日期输入框会预填一个建议日期：北京时间 07:00 前为当天，之后为次日。请自行核对并修改；预填日期不代表已启用任何任务。可以设置今天至未来 30 天内的一天。

| 设置 | 含义 |
| --- | --- |
| 任务日期 | 本次放号与打球日期，必须明确选择。程序不会自动延续到第二天。 |
| 放号时间 | 默认 07:00，北京时间；如学校调整，请按实际规则设置。 |
| 运行时长 | 默认 15 分钟，可设 1–60 分钟，到截止时间后停止新的提交。 |
| 预约模式 | 单选“只抢免费场”“免费优先，允许付费备选”或“只抢付费场”。周内三项均可选，首次默认只抢免费场；周末仅开放只抢付费场。 |
| 免费打球时段 | 只抢免费场或免费优先模式下，由本人核实后填写，格式 `HH:MM-HH:MM`，例如 `13:10-14:40`。`15:30-17:00` 只是常用预填值，程序不推算学校的免费时间，仍只接受网页明确标为免费的场次。只抢付费场时隐藏且无需填写。 |
| 付费场最早开始 / 最晚结束 | 允许付费的模式下显示，限制打球时段，默认 14:00–21:00，可修改。表示场次不早于 14:00 开始、不晚于 21:00 结束，与付款时间无关。只选完整落在范围内的 1 小时或 2 小时场次，范围内优先下午场。 |
| 每场上限（元） | 允许付费的模式下显示，可设 1–30 元，默认每场最多 30 元；按学生价 15 元/小时估算，实际支付金额还会再次核对。 |
| 先只抢免费场（秒） | 仅在“免费优先，允许付费备选”模式显示，可设 0–300 秒。放号后的前 N 秒只尝试填写的免费打球时段，之后免费仍优先，同时可尝试付费场；默认 15 秒。设为 0 时，从放号起免费优先并允许付费。只抢付费场时隐藏且无需填写。 |
| 查询间隔（秒） | 放号后 0–60 秒、60–180 秒、180 秒以后分别设置，每项允许 0.5–60 秒，默认及推荐为 0.5 / 1 / 3；“恢复推荐值”可还原这三项。 |
| 同行人 | 填写除本人外 1–5 位同行人的姓名及学校账号；不要填写密码。 |
| 自动勾选条款 | 默认关闭。只有本人阅读当前学校条款并授权后，才允许程序勾选。 |

### 选哪一种预约模式

周内（周一至周五）可以选择全部三项，首次使用默认“只抢免费场”。通过单选项确认当前模式；蓝色提示只解释操作，例如“只尝试填写的免费时段，不考虑付费场”或“放号即尝试付费范围内场次，下午优先，抢到一场即停止”。免费优先模式则说明当前具体时段和秒数。

- **只抢免费场**：只预约填写的免费打球时段，不考虑付费场。只显示免费时段，隐藏付费打球时段、每场上限和“先只抢免费场（秒）”。
- **免费优先，允许付费备选**：同时显示免费时段、付费打球范围、每场上限及“先只抢免费场（秒）”。例如免费时段填 `15:30–17:00`，秒数填 `15`，表示**放号后的前 15 秒，只尝试 15:30–17:00 的免费场；之后免费仍优先，同时可尝试付费场。**若 07:00 放号，07:00:15 之前只考虑填写的免费场，07:00:15 起允许付费备选。设为 `0` 时，从放号起免费优先并允许付费，没有“先只抢免费”的阶段。
- **只抢付费场**：周内同样支持此选择。放号即查询付费打球范围内的场次，下午优先，不尝试免费场；只显示付费时段与每场上限，无需填写免费时段或等待秒数。学生价 1 小时 15 元、2 小时 30 元，每场不超过你填写的上限，最高 30 元。

**周末（周六、周日）没有免费场，只能选“只抢付费场”**，另外两项不可选。放号即查，只显示付费设置。周末期间保存设置不会覆盖原来的周内模式；切回周内日期会恢复原选择。各模式隐藏的免费时段、等待秒数和付费范围也会保留。

旧版的付费勾选框已移除。首次读取旧设置时，原来勾选了付费备选会迁移为“免费优先，允许付费备选”，否则迁移为“只抢免费场”；不会把旧设置直接解释为周内只抢付费场。

免费优先模式的说明会跟随你填写的免费打球时段及秒数更新。**生成免费或付费的任一场订单后，就停止继续抢场**；付费仍需本人付款，设置的秒数与自动付款无关。

允许付费时，优先选择你设置的范围内、开始时间处于 **12:00–18:00（不含18:00）** 的下午场。任意场地均可，最多生成一个订单。

星期规则按周一至周五、周六至周日区分，不自动推算节假日或调休。程序仍核对网页实际可用状态、免费标记与金额，不保证某天一定有免费场或任何可用场次。

### 查询间隔怎么设置

“查询间隔（秒）”数值越小，查询越频繁。三项可独立设置，不要求递增：

| 放号后经过时间 | 默认 / 推荐间隔 | 对应最多查询频率 |
| --- | --- | --- |
| 0–60 秒（不含 60 秒） | 0.5 秒 | 每秒 2 次 |
| 60–180 秒（不含 180 秒） | 1 秒 | 每秒 1 次 |
| 180 秒以后 | 3 秒 | 约每 3 秒 1 次 |

每项可填 **0.5–60 秒**的小数；点击“恢复推荐值”可恢复 0.5 / 1 / 3 秒。这些值是相邻两轮**开始查询的最小间隔**，上一轮没有结束时不会叠加请求，实际频率取决于网站响应速度。

网站繁忙时自动按 2、4、8 秒退避；如果你设置的查询间隔更长，则继续采用较慢的个人设置。查询设置保存在本机，下次打开沿用；开始前的任务摘要会列出三项间隔，请一起核对。

该设置只影响查找可用场地的节奏，不改变异常弹窗的反复确认、同一场次的提交重试或支付流程。

## 3. 开始与登录

1. 核对日期，单选预约模式，再核对对应打球时段、每场上限、查询间隔和同行人信息。如需自动勾选条款，先选中相应选项，再点击“确认设置并开始”并确认任务摘要。任务开始后设置不可修改。
2. 在程序新开的 Chrome 中自行登录学校。用户名、密码和验证码只在学校网页填写。
3. 等待程序校验目标场馆、日期和页面。出现已准备或等待放号的提示后，保留程序和浏览器窗口。
4. 如果开始前选中了“登录后阅读当前学校条款，并选择是否授权程序自动勾选”，登录后在助手弹出的条款窗口中阅读，点击“已阅读，同意本次自动勾选”；也可以选择“本次手动勾选”。授权只对本次任务有效，不会保存给下次使用。没有授权时，条款页出现后需要你本人勾选，程序再继续。

任务运行期间请保持电脑开机联网、插电、不休眠、不合盖。不要同时手工点击提交、切换场次或用另一个程序操作这份任务的浏览器；修改设置请先停止任务。系统关机、合盖和更新仍可能中断运行。

## 4. 预约与重试如何进行

程序先填写目标场次和同行人，再提交学校校验，进入条款页后点击“去支付”。这个按钮对免费场也存在，免费场点击后应直接生成预约结果。

出现已识别的“网络异常，请稍后再试”等弹窗时，程序会持续点击“确认”。如果关闭后又出现同类弹窗，就继续确认。弹窗完全关闭、前一次请求已结束，而且学校明确返回失败后，再次点击**同一场次**的“去支付”，重复流程直到核验到订单、场次已满、任务停止或到达截止时间。

“点击失败提示”与“提交结果未知”不同。断网、HTTP 错误或响应丢失时，订单可能已在学校生成，程序会先查已有订单；仍无法确认就暂停并提示你核对。未知提示、条款变化和金额异常也会暂停。请不要在结果未知时马上重新启动下单。

查询按你设置的三阶段间隔依次执行，默认 0.5 / 1 / 3 秒；繁忙时退避 2 / 4 / 8 秒，个人设置更慢时采用较慢值。具体含义见上文“查询间隔怎么设置”。

## 5. 看懂结果

| 程序提示 | 你需要做什么 |
| --- | --- |
| 等待登录 / 登录失效 | 在独立 Chrome 学校页面自行登录，按界面提示继续。 |
| 等待放号 / 已准备 | 保留程序和浏览器，等待指定日期时间。 |
| 正在确认学校提示 / 重试同一场次 | 等待程序处理，不要同时手工提交。 |
| 需要勾选条款 | 本人阅读学校条款；如同意，在网页勾选。 |
| 免费预约已确认（`CONFIRMED`） | 程序已核对目标免费订单，仍建议在学校“我的”中查看有效预约。 |
| 付款窗口已显示（`PENDING_PAYMENT`） | 尚未付款。核对金额和订单，在微信/支付宝中本人完成付款，并回学校核验。 |
| 支付需核对（`PAYMENT_REVIEW`） | 可能已有待支付订单，请在学校“我的”中查看并本人继续付款。 |
| 订单待核验（`ORDER_CREATED`） | 已到订单页，但内容或状态尚未完整确认，需本人核对。 |
| 需要核对 / 提交结果未知 | 先查学校“我的”中的已有订单，确认后再决定下一步。 |
| 已停止 / 已截止 | 不再进行新的提交；已在学校创建的订单仍需本人处理。 |

付费场会核对学校页面金额，尝试选择可识别的微信或支付宝方式，并点击学校第二层“去支付”，直至识别到付款窗口。登录支付账号、输入密码、扫码及最终付款均由本人完成。真实学校第二层付款页尚未完整验证；如果界面无法识别，请根据提示在浏览器继续处理已有订单。

## 6. 停止与再次使用

点击“停止任务”可结束任务，正在进行的页面操作可能需要几秒才能返回，随后关闭助手启动的浏览器。关闭助手窗口也会请求停止；停止前请先核对或处理待支付订单，已有学校订单不会被自动取消。

再次预约需要重新设置明确的日期并开始任务。保存的设置不会自动启动预约，也不会每天定时运行。

## 7. 常见问题

**双击无法运行**：先确认解压完整、系统为 Windows 10/11 64 位，并保留运行包内的全部文件。程序未做数字签名时，Windows 可能显示发布者未知；请核对发布来源与发布页校验值，再自行决定是否运行。

**浏览器打不开或首次等待很久**：确认 Chrome 已安装，网络能访问学校和驱动下载服务。先关闭本程序后重新打开；不要下载参考仓库里来源不明的旧驱动来替换。

**页面日期不符或提示规则变化**：程序会暂停。检查学校实际放号规则和所选日期；不要通过修改网页绕过校验。

**已经出现待支付，程序却没有报成功**：这是正常区分。付费订单需要你付款，最终以学校显示的有效订单为准。

**没有抢到场**：网站拥堵、登录失效、无可用场次或页面调整都可能导致失败，程序不能保证成功率。

当前仍为测试版，尚未在另一台干净电脑验证；真实学校第二层付款页也尚未完整现场验证。本机自动测试和启动检查不代表高峰期预约成功率。

## 8. 本地数据与反馈

本地设置与运行资料位于 `%LOCALAPPDATA%\NEUCourtBooking`，可点击“打开本机数据目录”查看。配置含同行人姓名、学校账号；日志和订单状态也可能含私人内容。公开版不自动保存登录后的网页源码或截图；你自己截取的图片也请先遮盖个人信息。不要将本机数据目录直接发给他人或上传 GitHub。

反馈时提供软件版本、Windows/Chrome 版本、问题发生的北京时间及已遮盖个人信息的报错。不要发送账号密码、验证码、cookie、支付码或完整订单页面。分享软件请使用原始运行包，不要把自己的数据目录一并打包。
