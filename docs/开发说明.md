# 🛠️ 源码与构建

需要 Windows、Chrome 和 **Python 3.11+**，建议使用 Python 3.12 x64。普通用户直接下载 [Windows 运行包](https://github.com/Oppie2333/neu-court-booking/releases/tag/v1.2.0-preview.3)。

## 从源码运行

双击项目根目录的 `启动源码版.cmd`，或执行：

```powershell
python -m pip install -r requirements.txt
python main.py
```

## 测试与打包

```powershell
python -m pip install -r requirements-dev.txt
python -m unittest discover -s tests
powershell -ExecutionPolicy Bypass -File scripts/build.ps1
```

输出目录为 `dist/NEUCourtBooking`，分发时压缩整个目录。版本记录在 `app_settings.py`、[VERSION](../VERSION) 和 [CHANGELOG](../CHANGELOG.md)，发布步骤见 [发布指南](发布到GitHub.md)。

本版 112 项测试通过；本地 Chrome 模拟覆盖繁忙后连续两次约满、保留同一登录继续换场及付款二维码交接。模拟未访问学校，不代表修复版在真实高峰下的成功率。
